# Regras do Projeto

## 🎯 Foco Atual do Projeto
- **Otimização do Banco de Dados Local**: O foco atual e prioritário do projeto é otimizar o banco de dados local (SQLite / Drizzle ORM).
- Priorizar a performance das consultas (queries), modelagem eficiente, indexação adequada, redução de latência/overhead de I/O e garantia de integridade relacional.
- Toda modificação estrutural, fluxo de dados ou nova feature deve levar em consideração o impacto e a eficiência no banco de dados local.
